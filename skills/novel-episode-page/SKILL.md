# 单集出图流水线（9:16 图文漫画）

**目标**：从节拍表到 9:16 成品漫画页的全链路。

> 适用形态：每集 5–11 页 9:16 竖版（1080×1920）。

---

## 开工第一件事（顺序不可跳）

1. 读本文件「铁律」
2. 读本集 `发布文案.md` 的 **「本集因果链」表**——逐页核对本页要表达的关键物件与动作
3. 按需读参考文件（见文末索引）：出图/返修看 `references/出图与返修手册`，分格气泡看 `references/分镜与气泡规范`，动脚本看 `references/脚本手册`，做新集看 `references/项目文档地图与发布规范`
4. 读 `.cursor/rules/` 四 mdc + `分析/漫改大纲.md` + `分析/出图策略优化.md`

---

## 铁律（违反必返工）

- **只做图片，不做视频。**
- **9:16 直出**：ImageGen `size:"1080x1920"`（实测输出 1072×1920）。不要再走 2:3 留白→裁剪。
- **分隔条 = 统一白条（业内漫画惯例）**：禁黑条。页内禁空白区：>120px 超宽白带用 `shrink_band()` 收窄成 ~48px 标准白条（下方内容拉伸补齐）。**页顶禁白条**：最顶部不允许有白条分割——交付前逐张扫 y0–140 均亮>230 白带，裁除后纵向回拉 1920。
- **画风 = 写实向国漫分格漫画**（明显偏写实）：真实人体比例、立体光影、清晰墨线、明亮干净上色。不是纯赛璐璐，也不是厚涂油画/照片感。
- **生图必挂两张参考**：`image1` = 本集已定稿的**无气泡底图**（画风 + 脸基准）、`image2` = 角色定妆照，`input_fidelity:"high"`。**禁用 640px 压缩图**（脸会漂移）；三图同传会超请求体上限。
- **画面 / 文字分离（方案A）**：生图提示词必写「不画任何气泡、旁白、拟声词、文字」；文字全部后期 PIL 叠。理由：生图文字不稳定（空泡、错字），而 AI 擦除会把已画的中文一起擦掉。
- **生图禁止画顶栏**：Logo / 章节行由 PIL 后期叠（仅 P01）。
- **内容必须与大纲一致**：每集的关键道具、事件必须能对应上原文。

## 流程

1. **定节拍**：按大纲/节拍表定本集页数与每页冲突；P01 取该集最强冲突（禁建立场），末页留下集钩子。分镜表**逐格写明说话人+挂哪张定妆**（「韩立问/令」这类简写会翻车）。
2. **集级设定卡**（5 分钟）：出场角色定妆号、反派族属负面清单（人类反派禁画妖化！）、道具素面清单、颜色纪律——**先验类缺陷全部堵在出图前**。
3. **出底图**：提示词按 **Prompt Skeleton v3 六段锁**（CHARACTER/ANATOMY/PROPORTION/LAYOUT/PROP+NO-TEXT/SCENE，见手册）；`size:"1080x1920"` → 落盘改名 `P0x_短名底图.png`。
4. **目检**：画风 / 脸 / 撞脸 / 道具文字 / 白背景 / 解剖（双手双腿）/ 相邻页是否撞图。不合格按**返修决策表**选最低成本路径，别赌高成本路径。
5. **去水印**：`remove_watermark()` v3；**严禁 AI 擦除**。
6. **P01 封面**：PIL 后期叠 Logo + 章节行（仅 P01；P02+ 一律无顶栏）。
7. **叠泡**：先写**因果链规划表**（说话人/台词/因果位/坐标），再落坐标（见下）。重出过的页**必须重跑 measure_gutters.py 再核坐标**。
8. **QA 门禁 + 交付**：`python tools/qa_check.py <集目录>` **零 ERROR** 才交付（7 项自动检查；WARN 逐条人工确认）；`present_files` 给出成品；更新 `发布文案.md`。

**集目录只放成品**——底图与单页叠泡脚本放项目级 `<项目>/工作区/<集名>/`（不写进集目录）。

成品统一 1080×1920；**白条规整在锐化之后还要再跑一遍**（`white_gutters(im)` 放 save() 里；锐化会推高缝线亮度）。

若本轮动过目录/文件名，额外跑 `python tools/check_refs.py`（引用体检，须 0 缺失）——挂图路径会因此失效而不自知。

## 提示词骨架（v3 六段锁）

```
[CHARACTER LOCK]
<角色名>脸部最高优先级严格照搬参考图2：脸型、眉、眼、鼻、唇全部照搬。
禁止美化、禁止换脸、禁止共用配角脸。
ENTIRE FIGURE — face, hairstyle, clothing, body proportions — MUST exactly copy reference image 2.
禁止横过额头的丝带/头巾。

[ANATOMY LOCK]
EXACTLY TWO legs. EXACTLY TWO arms.
<双臂各自用途：right hand grips saber raised, left hand clutches wounded shoulder>
禁止藏手入体。禁止断肢。

[PROPORTION LOCK]
Head proportionate to body. 禁止头身错位。
<角色A> only one head taller than <角色B>.

[LAYOUT]
9:16 竖版漫画分格，海贼王 1189 式不规则格，2 层为主、3 层最多。
禁 4 层+密叠。
构图主体居中或偏左，避开 y240–1680 顶栏安全区。
封面构图：NO large empty black areas, ground extends to the bottom edge.

[PROP+NO-TEXT LOCK]
所有道具一律素面禁文字：<道具清单>。
禁止任何文字、气泡、旁白、拟声词、印章、Logo、Watermark。

[SCENE]
<具体场景描述>
<光线、天气、氛围>
<色板关键词>
```

## 叠泡纪律

- 按分镜阅读顺序（左→右、上→下）交代；**一句一泡、每格最多一泡**；群像场景才允许一格两泡且横向分开、尾巴分别指人；
- 每泡必须有字、短句中文；引文用直角引号「」，心里话末尾用「……」；
- 地点框只放一次（左上角）；
- 函数（来自 `tools/bubble_lib.py`）：
  - `bubble()` 对白
  - `mental_bubble()` 心里话（云朵边）
  - `burst_bubble()` 厉声呐喊（锯齿爆框）
  - `narration()` 旁白·解说·时间跳跃
  - `loc_box()` 地点
  - `float_word()` 浮字·拟声·招式
- 单页脚本一律叫 `apply_pXXX_vN.py`

## 返修决策表（见手册）

| 缺陷 | 最低成本路径 | 禁用的路径 |
|------|------------|----------|
| 撞脸（配角像主角） | img2img ENTIRE FIGURE + FACE LOCK 提示词 | 整页重出 |
| 脸漂移 | 换更高清的 `image2` 定妆照；PIL 缩 1200px | 加大生图分辨率 |
| 道具带字 | 提示词重写 + ENTIRE FIGURE 返修 | PIL 涂白（必留痕） |
| 白背景 | 提示词加 NO white background | PIL 涂黑 |
| 额头带子 | img2img + REMOVE headband ACROSS THE FOREHEAD | PIL 裁剪 |
| 断肢/藏手 | 提示词加 ANATOMY LOCK 写死双臂各自用途 + 整页重出 | PIL 贴回 |
| 头身错位 | 整页重出 + PROPORTION LOCK | PIL 缩放 |
| 撞图（相邻两页同构图） | 整格重出 + 提示词写不同动作/景别 | 简单改构图 |
| 面具偏白 | PIL 压暗法（L>阈值 亮部乘 0.34 冷色调） | img2img 重绘 |
| 顶栏遮挡 | PIL 整体下移 + 顶部天空延展（**只取纯天空区**） | 整页重出 |

## 封面顶栏纪律

- **仅 P01 叠 Logo+集号**，**P02+ 不叠**大顶栏
- **主图 = 叠泡脚本刚生成的浮字成品**，在集目录（DIR）里——脚本 save() 全部写集目录，喂工作区路径会拿到旧副本
- **封面构图纪律**：整页满铺，禁大片黑/白空背景（提示词明写 NO large empty black areas、ground extends to the bottom edge）
- **抖音封面按 3:4 居中裁切**——顶栏下移进安全区（y240–1680）成浮动标题板、主图整页零裁切
- **封面浮字 y≥640**

## 发布交付（条视图）

- **一条 5–6 张，一条 ≠ 一集**。10–11 页直接发是完播率第一杀手。
- **交付 = 图 + `发布文案.md`，缺一不算完成**。
- **发布目录 `<项目>/发布/C0N_短名/`**（唯一上传入口）：内含 `01–06_*.png`（**文件序号即上传顺序**）+ `发布文案.md`（标题主推/备选、描述留空、置顶二选一、BGM、上传顺序、因果链自检）。
- **标题**：`<项目名>｜<结果前置句>`，**18–21 字**。
- **`发布文案.md` 五件套**：标题（主推 + 备选）／描述留空／置顶二选一／**BGM 必须是具体曲名 + 演唱者**／上传顺序。
- **末页叠关注条**：`narration(d, x, y, lines, size=44)`，压底死区（距底边 ~84px）

## 已知坑位（精选）

| 坑 | 规避 |
|----|------|
| 模型看不到图时「凭印象目检」 | 先再试一次直接 Read 目检（"内容过滤"多为暂时性）；确认不行才退「盲操作法」（亮度图定版面 + 像素量气泡） |
| 模块级叠泡代码被 import 重跑覆盖成品 | PIL 公共库只 import 不写成品；`bubble_lib.py` 严禁模块级代码 |
| Edit 偶发"报成功但未落盘" | 每次编辑后用 Grep 复核文件实际内容 |
| Bash `grep "a\|b"` 交替模式**静默返回空** | 多模式检索一律用 Grep 工具 |
| 局部返修贴回三条 | img2img 输出会重组构图 → 按特征估缩放+位移羽化贴回 |
| 断肢/藏手型渲染错误 | 提示词加 ANATOMY LOCK + 写死双臂各自用途；只写 no extra arm 不够 |
| 头身错位/撞脸他角 | 整页重出加 PROPORTION LOCK + FACE LOCK img2img 补刀 |

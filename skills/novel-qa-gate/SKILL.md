# QA 门禁流水线

**目标**：成品页交付前的机械检查 + 全项目引用体检，把人眼会漏的问题变成 0/1 退出码。

> QA 门禁 = 自动化 + 人眼补漏。自动化解决"反复检查同样的事"的成本，人眼补"AI 模型能力之外"的问题。

---

## 开工第一件事

1. 读本文件「检查项」节
2. 跑 `python tools/qa_check.py <集目录>` 拿自动报告
3. 跑 `python tools/check_refs.py` 拿引用报告
4. 对 ERROR 必修，对 WARN 逐条人工确认
5. 写交付报告

---

## 7 项自动检查（qa_check.py）

| # | 检查 | ERROR | WARN |
|---|------|-------|------|
| 1 | 命名与尺寸规范 | 命名不合规 / 同集尺寸不一致 | 尺寸非 9:16 |
| 2 | 黑条/空白带检查 | 黑条残留（禁黑条新规）| >120px 超宽白带 |
| 3 | 页边白边 | —— | 左右白列 / 底部白行 >6px |
| 4 | 水印残留 | —— | 右下角亮笔画像素 >120 |
| 5 | 相邻页撞图 | —— | 相邻页灰度相关系数 >0.93 |
| 6 | 气泡体检 | 空泡 / 泡内糊死 | 候选数过少 |
| 7 | 画风离群 | —— | 同集内 >1.5σ |

**退出码**：0 = 全部通过；1 = 有 ERROR（必修）；2 = 仅 WARN（人工确认）

## 用法

```bash
# 必跑：交付前
python tools/qa_check.py <集目录>             # 检查 P*.png 成品
python tools/check_refs.py                    # 引用断链体检

# 常用选项
python tools/qa_check.py <集目录> --json      # 输出 JSON（给脚本消费）
python tools/qa_check.py <集目录> -v          # 附每页统计明细
python tools/check_refs.py -v                 # 列出每处引用的来源与行号
python tools/check_refs.py <子目录>           # 只扫指定
python tools/check_refs.py --ext .py          # 只扫指定扩展名的载体文件
```

## 各检查项的判定细则

### 1. 命名与尺寸规范

- **必含** `P\d{2}[_\-]*.png`（如 `P01_xxx.png`）
- **排除** `_预览3x4`、`_浮字`、`_底图`、`预览` 等中间件后缀
- **同集所有页尺寸一致**
- **尺寸 9:16**（1080×1920 或 1072×1920 均可，比例误差 ≤0.02）

### 2. 黑条/空白带检查（2026 新规：分隔条 = 白条，禁黑条）

- **黑条 = ERROR**：整行/整列近黑且均匀（带内 std<8.0）的条带 → 残留黑缝
- **超宽白带 = WARN**：>120px 的近白条带 → 疑似未铺满的空白区
- 实测分隔条 36~60px，海贼王参考 40~60px

### 3. 页边白边

- 左缘白边 >6px → 应拉伸铺满或裁除
- 右缘白边 >6px → 应拉伸铺满或裁除
- 底部白尾 >6px → 应拉伸铺满或裁除
- 这是「该铺到边缘但没铺到」的常见 bug

### 4. 水印残留

- 看精确文字区 `(0.795w..w, 0.958h..h)`
- 亮像素 >120 且聚成多个小连通域（每块 <400px、块数 ≥4）= 文字状笔画
- 自然亮纹理（草地高光/衣袍反光）是大块平滑区域，不会命中

### 5. 相邻页撞图

- 32×32 灰度相关系数 >0.93 → 疑似同构图重复
- 是 img2img 复制上页构图的常见 bug

### 6. 气泡体检

- 亮斑 + 墨线轮廓识别气泡
- **空泡**：墨色占比 <0.005 → 没写字的废气泡
- **糊死**：墨色占比 >0.5 → 文字溢出气泡边界
- 气泡大小过滤：面积 ∈ [0.002, 0.06] × 页面积；宽高比 ∈ [0.45, 2.4]

### 7. 画风离群

- 每页 mean L / mean S 离群（同集内 >1.5σ）→ 提示核对是否同集漂移
- 不是错，但提示「是不是这一张的色调用错了」

## 引用断链体检（check_refs.py）

**何时必跑**：
- 改过目录结构
- 改过文件名
- 清过旧文件
- 交付前

**判定口径处理三类「假阳性」**：
- **外链**（http/https）——先整段剔除
- **历史日志**（`memory/YYYY-MM-DD.md`）——记的是「当时」路径，跳过
- **前瞻引用**（计划中尚未创建的文件）——用白名单声明

**前瞻引用白名单**：
```bash
# 编辑 tools/check_refs_forward.txt，每行一个"仓库相对路径"
# 该文件确实被文档引用，但计划中、尚未创建
```

## 返修决策表

| QA 报告 | 优先级 | 处理方式 |
|---------|-------|---------|
| 黑条残留 | ERROR 必修 | PIL 白条化 `white_gutters()`；或整页重出 |
| 空泡/糊死 | ERROR 必修 | 重跑叠泡脚本；坐标重算 |
| 命名不合规 | ERROR 必修 | 重命名 |
| 尺寸不一致 | ERROR 必修 | 调整底图 |
| 超宽白带 | WARN | `shrink_band()` 收窄；或检查构图 |
| 页边白边 | WARN | 拉伸铺满或裁除 |
| 水印残留 | WARN | 检查人工目检 10 秒确认是否真水印 |
| 相邻页撞图 | WARN | 提示「可能撞图」，人眼确认 |
| 画风离群 | WARN | 提示「色调用错」，人眼确认 |

## 完整交付前自检清单

```bash
# 1. 引用体检
python tools/check_refs.py

# 2. 集目录 QA
python tools/qa_check.py <集目录>
#    期望：退出码 0（全部通过），或退出码 2（仅 WARN）

# 3. （如果需要）相邻集目检
python tools/qa_check.py <相邻集目录>
#    对比画风是否一致

# 4. 写交付报告
# - 用了哪些 skill
# - 修了哪些 ERROR
# - WARN 的人工判断
# - 还有哪些 TODO
```

## 已知坑位

| 坑 | 规避 |
|----|------|
| QA 校验器会连你自己的记忆/文档一起查 | 写"已失效路径"当例子时别写成完整路径字面量 |
| 检查器一有失败就无法当门禁 | 给"计划中尚未创建"的引用留白名单机制 |
| QA 只看机械特征 | 撞图/撞脸/画风离群必须人工目检 |
| Edit 偶发"报成功但未落盘" | 每次编辑后用 Grep 复核文件实际内容 |
| Bash `grep "a\|b"` 交替模式**静默返回空** | 多模式检索一律用 Grep 工具 |

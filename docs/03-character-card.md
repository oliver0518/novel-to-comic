# 03 · 角色定妆体系详解

## 为什么必须做角色定妆

**核心问题**：AI 生图模型的角色一致性是出了名的烂。

实测：不挂定妆照，**同一个角色 5 张图可能出 5 张脸**。
读者看到第 3 张就放弃「这是同一个人」的判断。

**角色定妆 = 把角色的脸/身/服/装备全部锁死**，让 AI 在每次出图时有一张精确的"参考图"。

## v2 双卡体系

### 为什么是双卡

| 卡 | 用途 |
|----|------|
| **写实完整人物卡** | 90% 的剧情场景用这张锁脸 |
| **Q 版人物卡** | 10% 的搞笑场景用（单集 1–3 处、每处 ≤2 秒）|

**实测**：写实↔Q 直接对切会出戏，必须各自独立卡。

### 双卡结构（写实 / Q 版 各一份）

```
┌────────────────────────────┐
│ 大肖像（主角半身像）       │
├─────────┬──────────────────┤
│ 资料栏  │ 性格特征 / 能力   │
├─────────┴──────────────────┤
│ 统一刻度三视图（正/侧/背）│
├────────────────────────────┤
│ 微表情六格（喜怒哀惊思等）│
├──────────────┬─────────────┤
│ 服饰六格     │ 装备六格    │
├──────────────┴─────────────┤
│ 色板（6 色 hex + RGB）    │
├────────────────────────────┤
│ 背景 / 所属世界观         │
└────────────────────────────┘
```

## 制作流程

### Step 1：考据（先证据后画）

从原文/设定大纲取证，**逐条带行号**：

- **台词金句**（定性格）
- **生活细节**（定道具/微表情）
- **战力表现**（定动作/装备）
- **信物归属**（别串人）
- **硬性禁项**（不能画什么）

### Step 2：10 张分件生图

**写实 5 张**：
- 主肖像
- 三视图（横版 3 列×2 行 1536×1024）
- 微表情（横版 2×3）
- 服饰图鉴
- 装备图鉴

**Q 版 5 张**：同套命名加 `_Q版`。

### Step 3：双卡组装

使用 `tools/compose_card.py`（参考实现），按你的项目改造。

### Step 4：目检

两张卡都要看：画风、名牌对齐、刻度线贯通、无多余特效。

### Step 5：引用表同步

**7–8 处**：

1. 设定大纲（人物谱）
2. 角色定妆 README（目录）
3. cursor/rules 角色规则
4. 漫改大纲（出场表）
5. 各 skill 的锁脸表
6. 各 skill 的 SKILL.md（写作角色定妆的指引）
7. MEMORY.md（主用总卡条）
8. 已出集的 `发布文案.md`

### Step 6：旧文件清理

**这一步最容易漏**。**同一轮做完，不许留成待办**。

## 锁脸句模板

**通用模板**（写到每个生图提示词首句）：

```
<角色名>脸部最高优先级严格照搬参考图2：
脸型、眉、眼、鼻、唇全部照搬。
禁止美化、禁止换脸、禁止共用配角脸。
ENTIRE FIGURE — face, hairstyle, clothing, body proportions —
MUST exactly copy reference image 2.
禁止横过额头的丝带/头巾。
```

**注意**：

- 必须写"最高优先级"——AI 默认不会把脸当最高优先级
- 必须写"ENTIRE FIGURE"——只锁脸会留下服装/身形不一致（实证：33 集 P04 五轮返修教训）
- 必须写"禁止横过额头的丝带/头巾"——这是 AI 的常见走偏

---

## 常见硬性禁项

不同题材有不同的禁项，但**写作时必须从原文/设定大纲抄，不要凭印象**：

| 题材 | 常见禁项 |
|------|---------|
| 修真/玄幻 | 法器一律素面禁文字；境界特效禁画乱 |
| 古风/武侠 | 现代用品禁出现；服饰符合朝代 |
| 校园/都市 | 学生发型禁画成职业人；校服细节准确 |
| 奇幻/西幻 | 装备风格统一；种族特征不串 |
| 非人形（兽/灵） | 锁脸 image2 禁挂人形分件（服装会串到兽身上） |

---

## 出图硬约束

- **挂图超限**：高清分件普遍 5–8MB，超 ImageGen 请求体上限报错。**先 PIL 缩到 1200px 高质量 JPG（约 300KB）存 /tmp 再挂**，锁脸不受影响。
- **六格图必须出横版 3 列×2 行（1536×1024）**，否则名牌错位。**方图会错位，必返工。**
- **底色统一浅色（≈240,237,231）**，否则组装后卡片色带不齐。
- **禁项逐条写进提示词**——不能只在文档里写。
- **服饰六格/装备六格一律素面禁文字标签**。

---

## 出图后必做目检

目检 10 张源图：

- 额头带子（横过额头的丝带/头巾）
- 断肢三脚（手臂/腿数量不对）
- 道具文字（装备上不该有的字）
- 撞脸（两张卡的角色互串）
- 鬼手/灵纹（不该出现的超自然特征）
- 眼镜与眉心印（不该有的现代元素）

发现问题**当场 img2img 或重出**，别带到组装阶段。

## 编号规则

**取该角色目录内下一个空闲编号**，惯例 `NN` 写实、`NN+1` Q 版。

参考（已落地的项目，编号按 `NN` / `NN+1` 习惯）：
- 修真类主角 30+31、修真类配角 32+33
- 反派类 30+31、好战类 23+24
- 灵宠类 25+26

跨项目沿用即可。

---

## 跨集复用

角色定妆一旦做完，**全项目所有集通用**：

- 出图时 `image2 = 角色定妆照/<角色>/NN_完整人物卡.png`
- 闪回场景用 `01_韩立_少年.png` 等旧期定妆
- 角色升级/换装时按本流水线**逐人升级**，不并行

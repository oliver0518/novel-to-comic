# 01 · 项目概览

## 一句话定义

**novel-to-comic** = 把任意网络小说/长篇故事改写成连载漫画剧集的**端到端方法论 + 工具集**。

输入：小说原文（txt / md / 用户贴正文）。
输出：可发布的完整漫画页（9:16 竖版，1080×1920）。

---

## 解决什么问题

把一部小说变成一部连载漫画，表面上是"画几张图"，实际上是四个层层叠加的工程问题：

| 问题 | 表面是 | 实际是 |
|------|-------|-------|
| **人物一致性** | "为什么配角都长一样" | 角色定妆 + 锁脸挂图 + 双卡体系 |
| **场景一致性** | "为什么这个大殿每集色调都不一样" | 场景定妆 + 色板 + 光影锁定 |
| **节奏与可读性** | "为什么看两页就划走了" | 节拍表 + 因果链 + 分镜规范 |
| **质量门禁** | "为什么这条数据经常要返工" | 7 项自动检查 + 引用体检 + 返修决策表 |

每个问题都有具体的工程答案，不是"AI 自己会解决"。

---

## 三层资产 + 一条流水线

任何故事都包含这三层资产：

```
┌─────────────────────────────────────────────────┐
│ Layer 3  漫画剧集  ←  最终交付                  │
│   ├─ 集 N：节拍表 + 因果链 + P0x 页            │
│   └─ 集 N+1：钩子接续                          │
├─────────────────────────────────────────────────┤
│ Layer 2  场景定妆  ←  出图前必备               │
│   ├─ 场景卡（环境、构图、光线、天气）          │
│   └─ 道具图鉴（武器、符箓、信物）              │
├─────────────────────────────────────────────────┤
│ Layer 1  角色定妆  ←  全局锁脸                  │
│   ├─ 写实人物卡（v2 完整人物卡）               │
│   └─ Q 版人物卡（搞笑嵌格用）                  │
└─────────────────────────────────────────────────┘
                              │
                              ▼
                    集级设定卡（出图前 5 分钟）
                              │
                              ▼
                  生图（9:16 直出 + 锁脸挂图）
                              │
                              ▼
              后期（去水印 → 叠气泡 → 顶栏 → 水印）
                              │
                              ▼
                    QA 门禁（零 ERROR 才交付）
```

**核心方法论**：**先定后出**。把所有的"长什么样""在哪""色温怎样"都在出图前定死，生图只负责"画这一格"。

## 适用边界

### ✅ 适合

- **网络小说 → 9:16 竖版图文漫画**（抖音/快手信息流）
- **长篇故事 → 漫画剧集**（每集 5–11 页）
- **同人/二创 → 漫画集**（需要锁脸的场景）
- **奇幻/玄幻/修真/武侠**（画风与场景复杂度高）

### ⚠️ 部分适合

- **现实题材**（场景复杂度低，可以不建场景定妆库，但角色定妆仍必要）
- **儿童向**（画风需调整，气泡字体放大）

### ❌ 不适合（暂不在本 skill 主路径）

- **视频漫剧**（本 skill 暂不展开；可参考《凡人修仙外传》视频线方法论）
- **纯文字小说的对话脚本**（不需要图像一致性）
- **超短篇**（如一个短篇一个画面，没有连载问题）

---

## 与传统漫改工作室的差异

| 维度 | 传统漫改 | novel-to-comic |
|------|---------|----------------|
| 画师 | 真人画师（每周 5–10 页） | AI 生图 + 后期 PIL |
| 锁脸 | 大量参考资料 + 实时对照 | 双图挂载（往期成品 + 定妆照） |
| 质量门禁 | 主编人工目检 | 7 项自动 + 人工目检 |
| 一致性 | 靠画师经验和多人交叉 | 靠定妆体系 + 双卡体系 |
| 节奏 | 周更 1 集 | 日更 1 集（实测） |

novel-to-comic **不是要替代画师**，而是要让 AI 生图在视觉一致性上达到可用水平。

---

## 已验证场景

- **《凡人修仙传》漫改工程**（第一卷 46 集，已出至 36 章）· 5 个月连载
- **《凡人修仙外传》视频线**（24 章）· 已稳定运行

跨场景复用的核心是：**定妆先行 + 方案A 文字分离 + QA 门禁**。

# 06 · 发布交付详解

## 发布单元 = 「条」

**一条 5–6 张，一条 ≠ 一集**。

实测数据：每集 10–11 页直接发是完播率第一杀手（平均只看 2.4/7 张）。

**交付 = 图 + `发布文案.md`，缺一不算完成**。

---

## 发布目录结构

```
<项目>/<原著名>/发布/C0N_短名/
├── 01_*.png                   # 文件序号即上传顺序
├── 02_*.png
├── ...
├── 06_*.png
└── 发布文案.md                # 五件套
```

**文件序号即上传顺序**——打开目录即可发，不让运营再判断发哪张。

## 发布文案五件套

### 1. 标题

**格式**：`<项目名>｜<结果前置句>`

**字数**：18–21 字（超 20 字信息流截断后半）

**示例**（修真类）：
- `<项目名>｜<结果前置句>`
- `<项目名>｜<动作 + 反差 + 余韵>`

**禁忌**：
- ❌ `<项目名>第N集｜<结果>` （不前置结果）
- ❌ `<项目名>｜<空泛描述>` （无具体结果）
- ✅ `<项目名>｜<结果 + 余韵>` （前置结果 + 留悬念）

### 2. 描述

**默认留空**。促评靠置顶，不靠描述/话题。

### 3. 置顶二选一

选 1 写：
- A：悬念式（"你觉得韩立能不能全身而退？评论区告诉我"）
- B：身份式（"七玄门的死契到底有什么秘密？我也不知道"）

不要两个都写——选一个能促评的。

### 4. BGM（必填）

**必须是具体曲名 + 演唱者**，不能写"低音铺底、渐进收紧、留白收拍"这种描述性词。

查 `<项目>/<原著名>/发布/BGM选曲表.md`（按情绪分档：文戏/悬疑用纯音乐或冷冽古风，战斗/高潮用国风战歌；同曲不超过 2 次）。

### 5. 上传顺序

**文件序号即上传顺序**——01 上传第一张，06 最后一张。

## 重剪 SOP（对已出成品页二次剪辑）

不重新生图，底图零成本。

### 步骤

1. **挑页**：10–11 页 → 5–6 页
   - 砍掉：建立场 / 过渡空镜 / 重复反应格
   - 留下：冲突 / 前因 / 结果

2. **换首图**：取本条最冲突帧
   - 原 P01 退到第 2–3 位

3. **改页序**：按"冲突 → 前因 → 结果"
   - **因果链不能断**

4. **换标题**

5. **处理首图顶栏**（唯一的真坑）：
   - 新首图取自 P02+ 无顶栏 → 取工作区底图重走叠泡补叠 Logo 浮动标题板
   - 原 P01 落到第 2 位 → 出无顶栏版，否则像两条作品的封面叠一起

6. **末页叠关注条**：
   - `narration(d, x, y, lines, size=44)`，压底死区（距底边 ~84px）

7. **写 `发布文案.md`**

8. **留档**：
   - `<项目>/工作区/重剪_C0N/`
   - 记"原集页 → 新序"对照表

## 重剪换封面三查

### 1. 顶栏遮挡判例

9:16 浮动标题板 = 实心面板 y240–624 全宽。

候选封面页必须裁剪目检构图主体是否落此区——眼睛/脸被盖 = 弃用。

### 2. 同图两现禁令

某页当封面（含泡）后，条内不再放该页普通版，用其余页补足 5 张。

### 3. float_word 右缘裁字

x 是左锚，x+len(text)×size+描边必须 ≤1072（曾裁掉「术」字）。

## BGM 选曲纪律

### 必填

**真实存在、抖音音乐能搜到的曲目**。

发布页"音乐"搜曲名 → 点"使用"，搜不到用备选。

### 按情绪分档

| 情绪 | 风格 |
|------|------|
| 文戏 | 纯音乐、冷冽古风 |
| 悬疑 | 古风悬疑、安静诡异 |
| 战斗 | 国风战歌、激扬 |
| 高潮 | 国风战歌、快节奏 |
| 搞笑 | 轻快、二次元、古风反差 |

### 同曲限制

**同曲不超过 2 次**——重复太多读者会察觉。

### 选曲表

`<项目>/<原著名>/发布/BGM选曲表.md`：

```markdown
| 条号 | 情绪 | 主选 | 备选 |
|------|------|------|------|
| C01 | 文戏 | 《<曲名>》-<演唱> | 《<备选>》-<演唱> |
| C02 | 战斗 | 《<曲名>》-<演唱> | 《<备选>》-<演唱> |
| ... |
```

## 如何选 BGM（新手版）

选曲的目标：**曲子的情绪和这一条的画面对得上，且同一首不反复出现**。按三步走：定档 → 搜歌 → 查重。

### 第一步：定情绪档

| 情绪 | 推荐曲风 | 节奏 | 动态 | 避开 |
|------|----------|------|------|------|
| 文戏 | 纯音乐、冷冽古风 | 慢 | 平稳、留白 | 副歌很强、人声占满的歌 |
| 悬疑 | 古风悬疑、安静诡异 | 慢到中 | 低音铺底，少突然爆点 | 明快欢快的古风流行 |
| 战斗 | 国风战歌、激扬 | 中到快 | 鼓点明显，有起伏 | 舒缓的纯音乐 |
| 高潮 | 国风战歌、快节奏 | 快 | 层层推高，结尾有收束 | 节奏平的背景乐 |
| 搞笑 | 轻快、二次元、古风反差 | 中快 | 跳跃、俏皮 | 悲壮沉重的战歌 |

- 一条只定一个情绪档，看整条的**主导情绪**（以占页数最多的情绪为准，末页钩子情绪优先），不要只看首图。
- 同一档可以有多首候选，但主选和备选要选同档、同节奏的歌。

### 第二步：在抖音音乐库搜歌

1. **先搜曲名**：选曲表里写的是具体曲名，先用曲名精确搜索。
2. **搜不到再用风格词**：两到三个词组合最稳，例如 `古风 纯音乐`、`国风 战歌`、`古风 悬疑`。词太长容易搜空。
3. **能用才算数**：只在列表里看到不算，进入详情页点"使用"能进发布页，才记入选曲表。
4. **热门标签会变**：音乐库的热门标签和榜单经常更新，不要把某个标签当长期依据，每次选曲重新搜。
5. **备选提前备好**：主选搜不到时直接换备选，别临场再找。

### 第三步：查重 —— 同曲不超过 2 次

**为什么要查**：

- 同一首曲子在一批条里反复出现，读者很容易听出来，连着两条重复尤其明显。
- 配乐高度重复会让不同条看起来像同一套流水线产物，削弱每条的独立感。

**怎么查（跨集核对）**：选曲表是**一个项目一份**，所有集的条都记在同一张 `BGM选曲表.md` 里，查重就查这张表。只统计**主选**列：

```bash
# 在 <项目>/<原著名>/发布/ 目录下执行，按使用次数降序列出主选曲目
awk -F'|' 'NR>2 && /《/ {print $4}' BGM选曲表.md | sed 's/^ *//;s/ *$//' | sort | uniq -c | sort -rn
```

- 输出里次数大于 2 的曲目需要替换。
- 同一首歌请统一写法（`《曲名》-演唱者`），写法不一致（如少了演唱者）会导致统计漏算。
- 替换时先换备选；备选也用过，就找同档同节奏的新曲。

空白模板见 [`templates/bgm-picker.md`](../templates/bgm-picker.md)。

## 常见发布问题

| 问题 | 解决 |
|------|------|
| 首图点击率低 | 换更冲突的帧；检查顶栏是否遮挡主体 |
| 完播率低 | 砍页数；调整前 3 张顺序；末页钩子更明确 |
| 评论数低 | 置顶二选一写得更具体；不要两个都写 |
| BGM 搜不到 | 用备选；不要硬写"低音铺底"等描述词 |
| 收藏率低 | 内容前置到首图；标题承诺的画面直给 |

# 07 · 经验教训汇总

> **每条规则都附带"这条经验是从哪个真实踩坑里来的"**。没有教训背书的规则不可信。

本文档按主题分类。引用时附原文出处。

---

## 1. 锁脸与一致性

### 1.1 单图挂载脸会漂移

**教训**：早期只挂角色定妆照，结果不同页的脸都长得不一样。

**根因**：单图挂载只能传递"脸"，传递不了"画风"。

**对策**：**双图挂载**——`image1` 往期成品页（画风基准）+ `image2` 角色定妆照（脸基准），`input_fidelity:"high"`。

### 1.2 ENTIRE FIGURE 必须锁，不只锁脸

**教训**：33 集 P04 五轮返修。每次 img2img 只锁脸，结果脸对了但服装/身形跑偏，被二次打回。

**根因**：AI 默认只参考"脸型 + 五官"，对"身形 + 服装"参考度低。

**对策**：提示词写「**ENTIRE FIGURE — face, hairstyle, clothing, body proportions — MUST exactly copy reference image 2**」。

### 1.3 头像带子是系统性缺陷

**教训**：P06/P07/P09/P11 都中招，AI 画出横过额头的丝带/头巾。

**根因**：训练数据中"额头带子"是常见元素，AI 默认会加。

**对策**：
- 提示词第一句写「禁止横过额头的丝带/头巾」
- img2img 修复时第一句写「CHARACTER LOCK + REMOVE headband ACROSS THE FOREHEAD」
- 实测一枪过。

### 1.4 发型判例：定妆本身就是顶髻

**教训**：16_韩立_四年后 定妆本来就是顶髻发髻+青束发带垂带，生图画成顶髻/丸子头=正确。但被当错误返修，浪费时间。

**对策**：判例入库——遇到生图"顶髻"先查定妆照是否是顶髻，再判是否返修。

## 2. 提示词与生图

### 2.1 禁画文字（方案A）

**教训**：早期生图让 AI 画气泡/旁白/拟声词，结果空泡、错字频发。试过后期 AI 擦除，结果连画面里的中文一起擦掉。

**对策**：**方案A 文字分离**——生图提示词必写「不画任何气泡、旁白、拟声词、文字」，所有中文后期 PIL 叠。

### 2.2 三图同传超请求体上限

**教训**：想 image1+image2+image3 三张图同传（画风+脸+场景），结果请求被拒。

**对策**：**双图挂载**，最多两张。如果场景也想锁，用文字描述色板。

### 2.3 640px 压缩图会脸漂移

**教训**：上传压缩过的定妆照，AI 锁脸失败，脸还是漂。

**对策**：**禁用 640px 压缩图**。高清分件普遍 5–8MB，挂前 PIL 缩到 1200px 高质量 JPG（约 300KB）存 /tmp，锁脸不受影响。

### 2.4 9:16 直出 vs 2:3 留白

**教训**：旧流程 2:3（1024×1536）+ 居中 9:16 柱留边 → 裁切。结果浪费返工。

**对策**：**9:16 直出**——`size:"1080x1920"`（实测输出 1072×1920）。不要再走 2:3 留白→裁剪。

## 3. 分格与画面

### 3.1 白条 vs 黑条

**教训**：旧流程"白缝涂黑"，结果看起来像"画被切了几段"，业内没人这么做。业内漫画分隔条就是白条。

**对策**：**白条分隔条**——`white_gutters()` 函数。`black_thr=45, white_thr=242, max_band=220, margin=6, uniform=8.0`。

### 3.2 页顶禁白条

**教训**：`white_gutters()` 的 margin 会漏掉页边白沿，交付前某页顶部 120px 全白。

**对策**：交付前逐张扫 y0–140 均亮>230 白带，裁除后纵向回拉 1920。

### 3.3 页底黑条误判

**教训**：37 集 P02/P04 是整页单格 + 均匀暗夜空顶部的页，`white_gutters(black_thr=-1)`（no_black）会把行 std<8 的均匀暗空误判成黑条刷成全宽白带。

**对策**：均匀度判据 `uniform=8.0` 排除夜景/黑袍等暗内容（std≈13-14）。旧值 14 会把近纯色夜空误判成涂黑缝吃掉，已收紧到 8。

### 3.4 >120px 超宽白带

**教训**：模型偶尔在两格间留出 100~200px 的空白带。

**对策**：`shrink_band(y0, y1, target=48)` 收窄为 48px 标准白条（下方内容垂直拉伸补齐）。调用后位于带下方的浮字/气泡 y 坐标要按拉伸比例重算。

## 4. 后期处理

### 4.1 模块级叠泡代码雷区

**教训**：早期 `apply_plan_a.py` 的模块级示例块让任何 import 都用旧底图重跑 P07、覆盖成品。2026-09-15 事故。

**对策**：**PIL 公共库只 import 不写成品**——`bubble_lib.py` 严禁模块级代码。本库的 `__main__` 只渲染样式样张。

### 4.2 narration() 误用

**教训**：直接量宽没在临时画布，结果"先画一次量宽"会在 (0,0) 留一条多余框。

**对策**：`narration()` 是直接绘制函数，不是干跑。量宽必须用 `probe.textbbox`。

### 4.3 AI 擦除会把画面中文一起擦掉

**教训**：用 AI 擦除功能去水印，结果连画面里要保留的中文一起擦掉。

**对策**：**严禁 AI 擦除**。用 PIL 固定区域垂直翻转填充 `remove_watermark()`。

### 4.4 双层水印 / 压在道具上

**教训**：默认右下区域 `(0.785W,0.95H)-(W,H)` 不一定够——双层水印、压在道具或发丝上时会漏。

**对策**：先扫水印真实坐标（半透明灰字亮度约 85–115，阈值别太高），双层水印/压在道具上时用**定点小补丁**或**垂直克隆**。

## 5. 撞脸与撞图

### 5.1 撞脸（配角像主角）

**教训**：配角脸和主角共用一张脸，读者分不清谁是谁。

**对策**：
- 提示词加「配角五官互异禁共用脸」
- 撞脸后用 img2img ENTIRE FIGURE + FACE LOCK 提示词「plain ordinary / NOT handsome / NOT sharp-jawed / NOT fierce」

### 5.2 相邻页撞图（同构图复制）

**教训**：img2img 时复制了上页构图，35 集 P05 / P06 是同一个构图。

**对策**：整格单独重出 + 提示词明确写不同动作/景别。重出后分格缝会变，必须重跑 `measure_gutters` 再核气泡坐标。

### 5.3 头身错位 / 撞脸他角

**教训**：生图时把矮个画成高个，或配角撞脸主角。

**对策**：
- 整页重出时加 PROPORTION LOCK：「Head proportionate to body / only one head taller than X」
- 重出后若脸仍太帅，对右列/单格做 FACE LOCK img2img 补刀
- 再按列矩形贴回（先测列竖缝与列内横缝坐标，矩形贴回对齐零风险）

## 6. 解剖与人体

### 6.1 断肢/藏手型渲染错误

**教训**：35 集 P02 前臂没入躯干消失。

**根因**：模型默认会把"难画的手藏进身体"。

**对策**：
- 提示词加 ANATOMY LOCK
- **写死双臂各自用途**（如「right hand grips saber raised, left hand clutches wounded shoulder」）
- 只写「no extra arm」不够，必须写死用途

### 6.2 玄字门徽执念缺陷

**教训**：「玄」字门徽跨集复发，PIL 整圆重铺素面徽（径向渐变+噪声）后修补。

**对策**：产物必查「玄」字门徽；一旦发现立即 PIL 整圆重铺。

## 7. 道具与场景

### 7.1 道具带字

**教训**：AI 画的道具经常带文字、印章、Logo。

**对策**：
- 提示词三条款必带：「所有道具一律素面禁文字」
- 提示词加 PROMPT 末段：「NO TEXT, NO WATERMARK, NO LOGO」

### 7.2 反派族属搞错

**教训**：野狼帮是人类，画成狼妖。

**对策**：**集级设定卡**——出场角色定妆号、反派族属负面清单（人类反派禁画妖化）。5 分钟写卡，省 5 小时返工。

### 7.3 集间道具连续

**教训**：集20 多本剑谱 → 集21 整套还回，但生图时少了 2 本。

**对策**：节拍表必写"集间道具连续"，出图前对表上集已亮相道具。

## 8. 封面与顶栏

### 8.1 顶栏遮挡

**教训**：9:16 浮动标题板 = 实心面板 y240–624 全宽。候选封面页没检查，主体被盖。C02 原 P07 封面即因此改 P09。

**对策**：换首图前必目检主体；构图主体避免落此区。

### 8.2 同图两现

**教训**：某页当封面（含泡）后，条内又放了该页普通版，看起来像两条作品的封面叠一起。

**对策**：某页当封面后，条内不再放该页普通版。

### 8.3 float_word 右缘裁字

**教训**：x 是左锚，x+len(text)×size+描边 > 1072 时，「火弹术」裁掉「术」。

**对策**：x+len(text)×size+描边 ≤ 1072 强制约束。

### 8.4 封面钩子不够

**教训**：背影/远眺类静态构图当封面钩子不够，被否。

**对策**：封面要"标题承诺的画面直给"（御风条封面 = 腾空御风）。

### 8.5 延展天空带串残影

**教训**：生图人物易放页面上部撞顶栏区，PIL 整体下移+顶部天空延展补救时，延展带取到发髻/人物，把残影拉进天空。

**对策**：**延展带只准取纯天空区**。接缝用 60-70px 线性交叉渐变消除。

## 9. QA 与门禁

### 9.1 QA 校验器会连自己的记忆/文档一起查

**教训**：写"已失效路径"当例子时，被自己的 QA 校验器查到，触发误报。

**对策**：写示例路径时拆开写或用文字描述，别写成完整路径字面量。

### 9.2 检查器一有失败就无法当门禁

**教训**：白名单机制缺失，导致计划中尚未创建的引用触发误报。

**对策**：**给"计划中尚未创建"的引用留白名单机制**——`tools/check_refs_forward.txt`。

### 9.3 必跑 check_refs 的时机

**教训**：挪过目录/改过文件名/清过旧文件后，文档里失效的引用路径没被发现。

**对策**：**改过目录结构必跑 `python3 tools/check_refs.py`**。0 缺失才算完。

## 10. 工程纪律

### 10.1 Edit 偶发"报成功但未落盘"

**教训**：编辑工具说"更新了"，但 grep 文件实际内容没变。

**对策**：每次编辑后用 Grep 复核文件实际内容。

### 10.2 Bash `grep "a\|b"` 交替模式静默返回空

**教训**：Bash 里 `grep "a\|b"` 会静默返回空。

**对策**：多模式检索一律用 Grep 工具，别信 Bash grep 的空结果。

### 10.3 模块级 vs 函数级

**教训**：模块级代码一旦被 import 就跑；函数级 import 后只占内存不执行。

**对策**：PIL 公共库**只写函数不写顶层执行**。`__main__` 块只渲染样式样张。

### 10.4 git 历史不可回收

**教训**：`git add -A` 一次带进 1.4GB 过程产物。

**对策**：
- `git add -A` 全量暂存前先 `du -sh` 看一眼
- 体积自检：`find . -type f -size +50M -not -path './.git/*'`
- 误加文件用 `git rm --cached` 取消跟踪，但**历史里仍有**

### 10.5 venv 路径不入库

**教训**：venv 路径各机器私有，写进 `requirements.txt` 反例。

**对策**：venv 路径不入库，**重建命令写进交接文档**。

## 11. 多会话协作

### 11.1 `git add -A` 会卷入别人未完成文件

**教训**：多会话并行时，`git add -A` 一次带进同事未完成的工作。

**对策**：用显式路径 `git add <路径>`，不用 `git add -A`。

### 11.2 编辑工具报成功但未落盘

**教训**：编辑工具偶发报成功但未落盘（不同会话/不同时间）。

**对策**：每次编辑后用 Grep 复核。

## 12. 通用原则

### 12.1 5 大类先验缺陷堵在出图前

**实战统计**：90% 的返工是这 5 类——撞脸、道具带字、白背景、额头带子、断肢。

**对策**：**集级设定卡**——5 分钟写卡，把这 5 类全部堵在出图前。

### 12.2 标点统一

**教训**：示例文档里半角 `""` 和全角 `「」` 混用，AI 引用时不知道用哪个。

**对策**：终稿校对时统一为 `「」`，全角逗号 `，`，全角句号 `。`。

### 12.3 引用方式

**教训**：文档里写"那张图"而不是"路径/文件名"，AI 引用时找不到。

**对策**：**引用 = 完整仓库相对路径** + 文件名。`角色定妆照/韩立/16_韩立_四年后.png`。

# 角色卡配置模板（v2 双卡体系）

> 这是一份**可直接复用**的角色卡配置模板。把 `<>` 里的内容换成你项目的具体值。

---

## 写实完整人物卡配置

```python
CHAR_FULL = {
    # ---- 文件路径 ----
    "parts": "_分件_<角色名>_v2",       # 分件源图目录
    "out": "NN_<角色名>_完整人物卡.png",  # 输出文件名

    # ---- 拼卡组件 ----
    "bust": "<角色名>_主肖像_源图.png",   # 大肖像
    "turn": "<角色名>_三视图_源图.png",   # 三视图
    "expr": "<角色名>_微表情_源图.png",   # 微表情
    "acc": "<角色名>_服饰图鉴_源图.png",  # 服饰图鉴
    "eq": "<角色名>_装备图鉴_源图.png",   # 装备图鉴

    # ---- 标题与副标题 ----
    "title": "<角色名>",
    "subtitle": "<身份> · <所属势力>",

    # ---- 资料栏 ----
    "info_pairs": [                    # 两列键值对
        ("性别", "<男/女>"),
        ("年龄", "<约 X 岁>"),
        ("身高", "<X> cm"),
        ("体重", "<X> kg"),
        ("种族", "<人类/灵兽/...>"),
        ("身份", "<身份>"),
    ],
    "info_full": [                    # 单行全宽
        "所属：<门派/势力>",
        "境界：<修真境界>",
        "信物：<信物清单>",
        "禁项：<硬性禁项>",
    ],
    "traits": "<性格特征标签>",
    "ability": "<能力简介>",
    "background": "<背景故事>",
    "world": "<所属世界观 / 势力>",

    # ---- 色板（6 色 hex + RGB）----
    "palette": [
        ("#<hex1>", "主色"),
        ("#<hex2>", "辅色"),
        ("#<hex3>", "对比色"),
        ("#<hex4>", "背景色"),
        ("#<hex5>", "道具色"),
        ("#<hex6>", "点缀色"),
    ],

    # ---- 六格标题与注解 ----
    "acc_names": [                   # 服饰六格标题
        "主形象", "战斗", "居家", "礼服", "便装", "伪装",
    ],
    "eq_names": [                    # 装备六格标题
        "<武器>", "<法器>", "<防具>", "<饰品>", "<随身>", "<信物>",
    ],
    "eq_notes": [                    # 装备六格注解
        "<注解 1>", "<注解 2>", "<注解 3>",
        "<注解 4>", "<注解 5>", "<注解 6>",
    ],
    "expr_names": [                  # 微表情六格标题
        "喜", "怒", "哀", "惊", "思", "疑",
    ],

    # ---- 体型 ----
    "cm_height": <身高 cm 整数>,

    # ---- 页脚 ----
    "foot": "原著 © <原著> · 仅供个人漫改练习",
}
```

## 配置键索引

### 公共键

| 键 | 类型 | 用途 |
|----|------|------|
| `parts` | str | 分件源图目录 |
| `out` | str | 输出文件名 |
| `bust` `turn` `expr` `acc` `eq` | str | 各组件源图名 |
| `title` `subtitle` | str | 卡片标题 |
| `info_pairs` `info_full` | list | 资料栏 |
| `traits` `ability` `background` `world` | str | 文字栏 |
| `palette` | list[tuple] | 6 色色板 |
| `acc_names` `eq_names` `eq_notes` `expr_names` | list[str] | 六格标题 |
| `cm_height` | int | 身高 cm |
| `foot` | str | 页脚 |

### Q 版额外

| 键 | 类型 | 用途 |
|----|------|------|
| `turn_front_x` | tuple | 正面视图 x 范围 |
| `expr_grid` | tuple | 微表情网格 |

### 非人形角色改名

| 键 | 默认 | 改名为 |
|----|------|-------|
| `acc_label` | "服饰图鉴" | "外形细节" |
| `eq_label` | "装备图鉴" | "叼物战绩" |

## 考据清单

写卡前先做考据，**逐条带行号**：

- [ ] 台词金句（定性格）
- [ ] 生活细节（定道具/微表情）
- [ ] 战力表现（定动作/装备）
- [ ] 信物归属（别串人）
- [ ] 硬性禁项（从设定大纲抄）
- [ ] 身高体重
- [ ] 6 色色板（hex + RGB）

---

## 出图后必做目检

- [ ] 额头带子（横过额头的丝带/头巾）
- [ ] 断肢三脚（手臂/腿数量不对）
- [ ] 道具文字（装备上不该有的字）
- [ ] 撞脸（两张卡的角色互串）
- [ ] 鬼手/灵纹（不该出现的超自然特征）
- [ ] 眼镜与眉心印（不该有的现代元素）

发现问题**当场 img2img 或重出**，别带到组装阶段。

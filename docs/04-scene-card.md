# 04 · 场景定妆体系详解

## 为什么需要场景定妆

**核心问题**：AI 生图的场景色调/光影/构图每张都不一样。

读者看到的现象：
- "为什么这个大殿每集色调都不一样？"
- "为什么昨天还是晴天今天就乌云密布了？"
- "为什么同一个湖在这集是绿的、在那集是蓝的？"

**场景定妆 = 把场景的色调、光影、构图、关键道具全部锁死**，让 AI 在每次出图时有一张精确的"环境参考图"。

---

## 场景分级

不是每个场景都要出定妆卡——按重要性分级：

| 场景等级 | 是否出场景卡 | 处理方式 |
|---------|------------|---------|
| **决战场景**（主角 vs 反派大决战） | ✅ 必出 | 场景卡 + 关键道具图鉴 |
| **重要场景**（秘境、门派大殿、主城） | ✅ 必出 | 场景卡 |
| **门派日常场景**（大厅、议事堂） | ✅ 出一次 | 公用场景卡 |
| **生活场景**（街道、田野、山林） | ❌ 不出 | 提示词写清环境即可 |
| **纯对话场景**（客栈、包厢） | ❌ 不出 | 提示词写清环境即可 |

**经验法则**：一个 46 集的项目大约需要 8–15 张场景卡。

---

## 场景卡的结构

```
┌─────────────────────────────┐
│ 场景主图（横版 16:9）       │
├─────────────────────────────┤
│ 视角 / 光源 / 色板          │
├──────────┬──────────────────┤
│ 构图三视图（平/俯/仰）│ 道具清单   │
├──────────┴──────────────────┤
│ 出场场景列表（哪几集哪几页）│
└─────────────────────────────┘
```

---

## 关键设计原则

### 1. 视角 = 角色入场的视角

场景卡的第一张图，必须是**主角（或本场景核心角色）进门那一刻的视角**。

理由：这是读者与场景建立第一印象的时刻，必须最稳定。

### 2. 色板 = 全集统一

同一场景的多集共用一张色板。**禁每集换色调**。

色板 6 色：
- 主色（占 60% 画面）
- 辅色（占 30%）
- 对比色（占 5%，强调用）
- 背景色（远景）
- 道具色（关键道具）
- 点缀色（特效、亮点）

### 3. 光影方向锁死

一旦定卡，光源方向（如"左上方自然光，下午"）锁死。**禁每页换光**。

理由：换光会让画面看起来像不同时间，但剧情是连续的——读者会出戏。

### 4. 道具一律素面禁文字

和角色定妆同口径。

### 5. 环境禁白背景

必须有具体地面、墙体、植被，否则模型会出白底废图。

## 制作流程

### Step 1：场景调研

从原文/设定大纲取证：

- **场景描写**（环境、空间、光线、天气）
- **道具描写**（武器、桌椅、符箓、器具）
- **氛围提示**（压抑 / 庄严 / 温馨 / 诡异）
- **出场人物**（哪些角色在这个场景有戏）
- **典型动作**（打斗 / 对话 / 仪式 / 修炼）

### Step 2：生图

**主图**（必出，1 张）：

```
[SCENE LOCK]
场景：<场景名>
视角：<平视/俯视/仰视>
光源：<自然光左上方 / 室内烛火 / 户外月光>
环境：<具体描述>
道具：<素面清单>
氛围：<情绪关键词>
画风：写实向国漫分格漫画
NO TEXT, NO WATERMARK, NO LOGO
```

挂参考：
- `image1` = 既有场景卡（如果有的话）
- `image2` = 即将出场角色的定妆照

### Step 3：写场景卡文档

`场景定妆照/<场景名>/README.md`：

```markdown
# <场景名> · 场景定妆卡

## 基础信息
- **编号**：NN
- **首次出场**：第 X 集
- **视角**：平视（角色入场视角）
- **光线**：左上方自然光，下午

## 环境要素
- **主建筑**：...
- **次要结构**：...
- **植被/天气**：...

## 道具清单
- 中心：...
- 边缘：...

## 色板
- 主色：#......
- 辅色：#......
- ......

## 出图提示词骨架
[SCENE LOCK]
......

## 引用场景
- 第 X 集 P01
- 第 X+1 集 P03
- ......
```

### Step 4：引用表同步

1. 设定大纲（场景章节）
2. 场景定妆 README
3. 漫改大纲（出场场景表）
4. 各集 `发布文案.md`
5. `MEMORY.md`

### Step 5：日志

追加到 `<项目>/memory/YYYY-MM-DD.md`。

## 道具图鉴

### 何时需要

- **重要武器**（主角的招牌武器）
- **重要符箓**（关键法术的道具）
- **重要信物**（角色之间的羁绊物）

### 结构

- 6 格素面图鉴 + 1 张整体展示
- 与角色定妆的"装备图鉴"对齐

---

## 场景定妆与角色定妆的配合

| 维度 | 角色定妆 | 场景定妆 |
|------|---------|---------|
| 锁定的对象 | 人 | 环境 |
| 双图挂载的 image2 | 角色定妆照 | 即将出场的角色定妆照 |
| 一致性问题 | 脸漂移 | 色调/光影漂移 |
| 出图频率 | 每页都挂 | 同一场景所有页都挂 |

**实战经验**：

- 同一场景多页时，主图和续图的色板必须对齐——可以用 `image2` = 场景主图（而非角色定妆）
- 跨集同场景时，必须保证色板完全一致——任何微调都会让读者察觉

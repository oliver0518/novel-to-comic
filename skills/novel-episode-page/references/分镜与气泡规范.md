# 分镜与气泡规范

> 这是 `skills/novel-episode-page/SKILL.md` 的配套参考文件。

---

## 一、分镜层数

| 层数 | 适用场景 |
|------|---------|
| **2 层** | 默认，最常见 |
| **3 层** | 复杂叙事或战斗 |
| **4 层+** | ❌ 禁止（密叠，不像漫画） |

**风格参考**：海贼王 1189 式不规则格。

---

## 二、分镜阅读顺序

**左 → 右，上 → 下**

---

## 三、构图纪律

| 维度 | 规则 |
|------|------|
| **主体位置** | 居中或偏左，避开 y240–1680 顶栏安全区 |
| **背景完整性** | 主体展开的环境必须看清 |
| **封面构图** | NO large empty black areas, ground extends to the bottom edge |
| **底死区** | y≥1660 关键对白/钩子勿入 |
| **重要冲突元素** | 避开 y240–620（被标题板盖住） |

## 四、气泡四型

| 类型 | 函数 | 用途 |
|------|------|------|
| **对白泡** | `bubble()` | 普通对话 |
| **心声泡** | `mental_bubble()` | 心里话、云状边 |
| **喊声泡** | `burst_bubble()` | 厉声呐喊、锯齿爆框 |
| **发颤泡** | `shaky_bubble()` | 吃惊、发颤 |
| **远声泡** | `whisper_bubble()` | 小声、远处 |

### 完整函数签名

```python
bubble(d, cx, cy, bw, bh, lines, size=36, tail=None, tail_len=34)
mental_bubble(d, cx, cy, bw, bh, lines, size=30, tail=None)
burst_bubble(d, cx, cy, bw, bh, lines, size=30, spikes=14, inner=0.80, tail=None, tail_len=40)
shaky_bubble(d, cx, cy, bw, bh, lines, size=30, tail=None, tail_len=34)
whisper_bubble(d, cx, cy, bw, bh, lines, size=24, tail=None, tail_len=24)
narration(d, x, y, lines, size=26, vertical=False, pad=12, style="box")
loc_box(d, x, y, text, size=34)
float_word(d, x, y, text, size=92)
```

## 五、旁白与地点

### 旁白（narration）

| 风格 | 用途 |
|------|------|
| `style="box"` | 普通矩形，米白底黑框 |
| `style="tag"` | 章节/场景窄条 |
| `style="rough"` | 手绘边 |
| `vertical=True` | 逐字竖排 |

### 地点框（loc_box）

- **左上角，整页只放一次**
- 函数：`loc_box(d, x, y, text, size=34)`

## 六、浮字 / 拟声词

- 函数：`float_word(d, x, y, text, size=92)`
- 金字 + 深色重描边
- 适合：拟声词、招式名

---

## 七、叠泡纪律

1. **一句一泡、每格最多一泡**
2. 群像场景才允许一格两泡且横向分开、尾巴分别指人
3. 每泡必须有字、短句中文
4. 引文用直角引号「」，心里话末尾用「……」
5. 地点框只放一次（左上角）
6. 末页叠关注条（`narration`）

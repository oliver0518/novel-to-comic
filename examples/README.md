## 真实的踩坑经验

所有方法论背后都有具体踩坑案例。下面摘录几个典型的：

### 案例 1：模块级叠泡代码雷区

**事故**：2026-09-15 一次 P07 出图时，import 了 `apply_plan_a.py`，结果模块级的示例代码自动跑了一遍，把已发布的 P07 用旧底图覆盖了。

**对策**：现在 `bubble_lib.py` 严禁模块级代码。本库的 `__main__` 只渲染样式样张。

### 案例 2：白条 vs 黑条

**事故**：旧流程把分格白缝涂成黑色，结果业内读者一眼看出"这是 AI 生成的"。业内漫画分隔条就是白条。

**对策**：2026-09-16 Oliver 定新规：分隔条 = 白条。开发了 `white_gutters()` 函数。`black_thr=45, white_thr=242, max_band=220, margin=6, uniform=8.0`。

### 案例 3：额头带子

**事故**：P06/P07/P09/P11 都中招，AI 画出横过额头的丝带/头巾，跨集复发。

**对策**：
- 提示词第一句写「禁止横过额头的丝带/头巾」
- img2img 修复时第一句写「CHARACTER LOCK + REMOVE headband ACROSS THE FOREHEAD」
- 实测一枪过。

### 案例 4：33 集 P04 五轮返修

**事故**：每次 img2img 只锁脸，结果脸对了但服装/身形跑偏，被二次打回。五轮返修。

**对策**：提示词必须写「**ENTIRE FIGURE — face, hairstyle, clothing, body proportions — MUST exactly copy reference image 2**」。不只锁脸。

### 案例 5：道具带字

**事故**：野狼帮的砍刀上出现了"野狼帮"三个字，墨大夫的药炉上出现了"墨"字。

**对策**：
- 提示词三条款必带："所有道具一律素面禁文字"
- 提示词末段："NO TEXT, NO WATERMARK, NO LOGO"

### 案例 6：反派族属搞错

**事故**：野狼帮（人类）被画成狼妖。

**对策**：**集级设定卡**——5 分钟写卡，"野狼帮 = 人类！禁画妖化"。从此不再出错。

## 复用建议

### 如果你也要做漫改

1. **从角色定妆开始**——这是基础
2. **先做 3 个角色的定妆**——找到节奏感
3. **用一份小说跑 5–10 集**——找到流水线节奏
4. **跑通 QA 门禁**——保证下限
5. **再扩展场景定妆**——提升上限

## 横向对比

novel-to-comic 不是唯一的方法论。常见的替代方案：

| 方案 | 优势 | 劣势 |
|------|------|------|
| **novel-to-comic（本项目）** | 通用化方法论 + 工具，跨项目可复用 | 需要自己跑 AI 工具链 |
| **传统漫改工作室** | 真人画师，画质上限高 | 一周 5–10 页，慢 |
| **ComicStudio / CSP** | 桌面工具成熟 | 上手成本高 |
| **NovelAI / NAI** | 出图工具现成 | 一致性差，不适合连载 |
| **Live2D / 视频漫剧** | 形态新颖 | 不是静态漫画 |

novel-to-comic 的定位：**让 AI 生图在视觉一致性上达到可用水平**，不替代画师，但比纯 NAI 强。

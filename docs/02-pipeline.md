# 02 · 端到端流水线

## 总览

```
阶段 0：项目初始化
  ├─ 建仓库
  ├─ 抓文稿 → 校对 → 落盘
  ├─ 设定大纲（世界观、势力、人物谱、术语表）
  └─ 建分析目录（漫改大纲、节拍表、推流策略）

阶段 1：角色定妆（详见 skills/novel-character-card/）
  ├─ 考据：台词金句、生活细节、战力表现、信物归属、硬性禁项
  ├─ 10 张分件生图（写实 5 + Q 版 5）
  ├─ 双卡组装（写实完整 + Q 版）
  └─ 引用表同步 + 旧文件清理

阶段 2：场景定妆（详见 skills/novel-scene-card/）
  ├─ 场景分级（决战 / 重要 / 日常）
  ├─ 出场景卡（主图 + 构图三视图 + 色板）
  └─ 道具图鉴（武器 / 符箓 / 信物）

阶段 3：漫改大纲
  ├─ 拆集：把整本按节拍切成 N 集
  ├─ 列原则：每集的主冲突、钩子、情绪曲线
  └─ 节拍表：每集按"在哪/谁/说什么/做什么/镜头怎么切"列

阶段 4：集级设定卡（出图前 5 分钟）
  ├─ 出场角色定妆号
  ├─ 反派族属负面清单
  ├─ 道具素面清单
  └─ 颜色纪律

阶段 5：单集出图（详见 skills/novel-episode-page/）
  ├─ 生底图（提示词 v3 六段锁 + 双图挂载）
  ├─ 目检（画风 / 脸 / 撞脸 / 道具 / 白背景 / 解剖 / 撞图）
  ├─ 去水印
  ├─ 叠文字（先因果链表，再落坐标）
  └─ P01 封面叠顶栏

阶段 6：QA 门禁（详见 skills/novel-qa-gate/）
  ├─ qa_check.py（7 项自动）
  └─ check_refs.py（引用体检）

阶段 8：发布交付
  ├─ 发布目录（一条 5–6 张）
  ├─ 发布文案.md（五件套）
  └─ 重剪 / 排期
```

## 阶段 0：项目初始化

### 0.1 建仓库

```bash
novel-to-comic/
├── <原著名>/                  # 例：你的小说名/
│   ├── _文稿/                  # 原著精校版
│   ├── 角色定妆照/             # 角色卡
│   ├── 场景定妆照/             # 场景卡
│   ├── 分析/                   # 漫改大纲、节拍表
│   ├── 工作区/                 # 过程产物（不入库）
│   └── 发布/                   # 发布单元
├── _shared/                    # 跨项目共用（可选）
│   ├── _工具/                  # 平台专用工具
│   └── _封面模板/
├── memory/                     # 项目记忆
├── SKILL.md
└── README.md
```

### 0.2 抓文稿

从网络小说站抓全文 → 校对 → 落盘为 `<原著名>_精校版.md`。

校对重点：
- 标点统一（半角 `""` → 全角 `「」`）
- 章节编号（与原网站一致）
- 人物名一致性（韩立/韩笠/韩粒 统一）

### 0.3 设定大纲

`<项目>/<原著名>/设定大纲.md` 包含：

- **世界观**：时代、地理、力量体系、社会结构
- **势力表**：门派/家族/组织 + 各自的标志色
- **人物谱**：主角 + 配角 + 反派（引用角色定妆目录）
- **术语表**：境界、武器、技能、信物
- **场景库**：地理场景列表（引用场景定妆目录）

### 0.4 分析目录

`<项目>/<原著名>/分析/`：

- `漫改大纲.md` —— N 集总表 + 集间钩子
- `第N集_节拍表.md` —— 每集节拍表
- `推流策略.md` —— 发布节奏与运营策略
- `复盘_第N-N集.md` —— 复盘报告

## 阶段 1：角色定妆

详见 [`skills/novel-character-card/SKILL.md`](../skills/novel-character-card/SKILL.md)。

### 关键节点

- **出场 ≥2 集的角色必出定妆**——否则每页脸都不一样
- **一个人物验收后再做下一个**——并行容易互相串设定
- **Q 版卡独立成卡**——不能塞在写实卡里

### 产出

- 写实人物卡（v2 完整人物卡）
- Q 版人物卡
- 10 张分件源图（仅返修用）
- 7 处引用表同步
- 旧文件清理

---

## 阶段 2：场景定妆

详见 [`skills/novel-scene-card/SKILL.md`](../skills/novel-scene-card/SKILL.md)。

### 关键节点

- **决战场景必出场景卡**——色调、光影、构图
- **色板 = 全集统一**——同一场景的多集共用一张色板
- **光影方向锁死**——一旦定卡，光源方向禁每页换

### 产出

- 场景卡（主图 + 三视图 + 色板）
- 道具图鉴
- 引用表同步

## 阶段 3：漫改大纲

### 拆集原则

| 拆集原则 | 说明 |
|---------|------|
| **按节拍不按章节** | 一章 2000 字可能拆 2 集，也可能不拆 |
| **每集 5–11 页** | 太少不够叙事，太多读者划走 |
| **P01 = 最强冲突** | 末页留下集钩子 |
| **建立场不堆在开头** | 第一节就出冲突，建立场放 P02+ |
| **集间道具连续** | 上集已亮相的道具下集须同一套 |

### 节拍表模板

```markdown
## 集 N · <短名>（基于小说第 X 章）

### 主冲突
一句话：...

### 节拍
- P01：<最强冲突帧>
- P02：<铺垫>
- P03：<升级>
- ...
- P0x：<钩子帧>

### 因果链
A 拿枪 → A 找 B → B 拒绝 → A 强攻 → C 插手 → ...

### 出场角色
- 主角：韩立(16_四年后)
- 配角：墨老(02_墨大夫)
- 反派：野狼帮 (人类！禁画妖化)

### 道具清单
- 小瓶（素面禁文字）
- 黑剑（无铭文）

### 环境
神手谷·药庐（禁白背景）
```

## 阶段 4：集级设定卡（出图前必做，5 分钟）

这是**最容易被跳过但最能省返工**的一步。

详见 `templates/episode-pacing.md`。

**核心动作**：在写提示词前，先用 5 分钟把出场角色定妆号、反派族属、道具清单、颜色纪律写在纸面上。

## 阶段 5：单集出图

详见 [`skills/novel-episode-page/SKILL.md`](../skills/novel-episode-page/SKILL.md)。

### 子步骤

1. **生底图**：提示词 v3 六段锁
2. **目检**：画风/脸/撞脸/道具/白背景/解剖/撞图
3. **去水印**：`bubble_lib.remove_watermark()`
4. **叠文字**：先因果链表，再落坐标
5. **P01 封面叠顶栏**

### 工作区结构

```
<项目>/<原著名>/工作区/<集名>/
├── P01_xxx_底图.png          # 无字底图（不入库）
├── P02_xxx_底图.png
├── ...
├── apply_p001_v1.py          # 单页叠泡脚本（不入库）
├── apply_p002_v1.py
├── ...
├── measure_gutters.py        # 分格测量（不入库）
└── generated-images/         # ImageGen 输出（不入库）
```

**集目录只放成品**：`<项目>/<原著名>/<集名>/P01_xxx.png`。

## 阶段 7：发布交付

详见 [`docs/06-publishing.md`](06-publishing.md)。

```
<项目>/<原著名>/发布/C0N_短名/

├── 02_*.png
├── ...

```

### 重剪（不重新生图）

10–11 页 → 5–6 张发布包，砍建立场/过渡空镜/重复反应格。

## 时间预算（一个 5 页集）

| 步骤 | 时间 |
|------|------|
| 节拍表 + 集级设定卡 | 15 分钟 |
| 5 张生图（每张 1.5 分钟） | 7.5 分钟 |
| 目检 + 返修 | 10 分钟 |
| 叠泡（5 张脚本） | 15 分钟 |
| P01 封面叠顶栏 | 3 分钟 |
| QA 门禁 + 修补 | 5 分钟 |
| **合计** | **~55 分钟 / 集** |

实战显示：熟练后单集可压缩到 30–40 分钟。

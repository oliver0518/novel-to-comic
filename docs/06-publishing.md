# 06 · 发布交付详解

## 发布单元 = 「条」

**一条 5–6 张，一条 ≠ 一集**。

实测数据：每集 10–11 页直接发是完播率第一杀手（平均只看 2.4/7 张）。

**交付 = 图 + `发布文案.md`，缺一不算完成**。

---

## 发布目录结构

```
<项目>/<原著名>/发布/C0N_短名/
├── 01_*.png                   # 文件序号即上传顺序
├── 02_*.png
├── ...
├── 06_*.png
└── 发布文案.md                # 五件套
```

**文件序号即上传顺序**——打开目录即可发，不让运营再判断发哪张。

## 发布文案五件套

### 1. 标题

**格式**：`<项目名>｜<结果前置句>`

**字数**：18–21 字（超 20 字信息流截断后半）

**示例**（修真类）：
- `<项目名>｜<结果前置句>`
- `<项目名>｜<动作 + 反差 + 余韵>`

**禁忌**：
- ❌ `<项目名>第N集｜<结果>` （不前置结果）
- ❌ `<项目名>｜<空泛描述>` （无具体结果）
- ✅ `<项目名>｜<结果 + 余韵>` （前置结果 + 留悬念）

### 2. 描述

**默认留空**。促评靠置顶，不靠描述/话题。

### 3. 置顶二选一

选 1 写：
- A：悬念式（"你觉得韩立能不能全身而退？评论区告诉我"）
- B：身份式（"七玄门的死契到底有什么秘密？我也不知道"）

不要两个都写——选一个能促评的。

### 4. BGM（必填）

**必须是具体曲名 + 演唱者**，不能写"低音铺底、渐进收紧、留白收拍"这种描述性词。

查 `<项目>/<原著名>/发布/BGM选曲表.md`（按情绪分档：文戏/悬疑用纯音乐或冷冽古风，战斗/高潮用国风战歌；同曲不超过 2 次）。

### 5. 上传顺序

**文件序号即上传顺序**——01 上传第一张，06 最后一张。

## 重剪 SOP（对已出成品页二次剪辑）

不重新生图，底图零成本。

### 步骤

1. **挑页**：10–11 页 → 5–6 页
   - 砍掉：建立场 / 过渡空镜 / 重复反应格
   - 留下：冲突 / 前因 / 结果

2. **换首图**：取本条最冲突帧
   - 原 P01 退到第 2–3 位

3. **改页序**：按"冲突 → 前因 → 结果"
   - **因果链不能断**

4. **换标题**

5. **处理首图顶栏**（唯一的真坑）：
   - 新首图取自 P02+ 无顶栏 → 取工作区底图重走叠泡补叠 Logo 浮动标题板
   - 原 P01 落到第 2 位 → 出无顶栏版，否则像两条作品的封面叠一起

6. **末页叠关注条**：
   - `narration(d, x, y, lines, size=44)`，压底死区（距底边 ~84px）

7. **写 `发布文案.md`**

8. **留档**：
   - `<项目>/工作区/重剪_C0N/`
   - 记"原集页 → 新序"对照表

## 重剪换封面三查

### 1. 顶栏遮挡判例

9:16 浮动标题板 = 实心面板 y240–624 全宽。

候选封面页必须裁剪目检构图主体是否落此区——眼睛/脸被盖 = 弃用。

### 2. 同图两现禁令

某页当封面（含泡）后，条内不再放该页普通版，用其余页补足 5 张。

### 3. float_word 右缘裁字

x 是左锚，x+len(text)×size+描边必须 ≤1072（曾裁掉「术」字）。

### 人工目检

发布前人工目检：

- 首图：构图是否吸引人点击
- 末页：钩子是否清晰
- 中间页：因果是否连贯
- 文案五件套是否齐全

## 排期与运营

### 排期表

`<项目>/<原著名>/分析/排期.md`：

- 每条计划发布日期
- BGM 主选 / 备选
- 标题主推 / 备选

### 复盘

每发 5–10 条做一次复盘：

- 完播率（用户看了几张）
- 点赞率
- 评论数
- 收藏率

把数据写进 `<项目>/<原著名>/分析/复盘_YYYY-MM-DD.md`，下次出图参考。

## 末页关注条模板

from PIL import Image, ImageDraw
from bubble_lib import narration

im = Image.open("末页.png").convert("RGB")
d = ImageDraw.Draw(im)

    style="box",

## BGM 选曲纪律

### 必填

**真实存在、抖音音乐能搜到的曲目**。

发布页"音乐"搜曲名 → 点"使用"，搜不到用备选。

### 按情绪分档

| 情绪 | 风格 |
|------|------|
| 文戏 | 纯音乐、冷冽古风 |
| 悬疑 | 古风悬疑、安静诡异 |
| 战斗 | 国风战歌、激扬 |
| 高潮 | 国风战歌、快节奏 |
| 搞笑 | 轻快、二次元、古风反差 |

### 同曲限制

**同曲不超过 2 次**——重复太多读者会察觉。

### 选曲表

`<项目>/<原著名>/发布/BGM选曲表.md`：

```markdown
| 条号 | 情绪 | 主选 | 备选 |
|------|------|------|------|
| C01 | 文戏 | 《<曲名>》-<演唱> | 《<备选>》-<演唱> |
| C02 | 战斗 | 《<曲名>》-<演唱> | 《<备选>》-<演唱> |
| ... |
```

## 常见发布问题

| 问题 | 解决 |
|------|------|
| 首图点击率低 | 换更冲突的帧；检查顶栏是否遮挡主体 |
| 完播率低 | 砍页数；调整前 3 张顺序；末页钩子更明确 |
| 评论数低 | 置顶二选一写得更具体；不要两个都写 |
| BGM 搜不到 | 用备选；不要硬写"低音铺底"等描述词 |
| 收藏率低 | 内容前置到首图；标题承诺的画面直给 |

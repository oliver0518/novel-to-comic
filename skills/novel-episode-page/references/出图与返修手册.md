### 返修止损纪律

**WARNING 级小瑕疵不值得重构整块区域**：

- 贴图/镜像/拉伸几乎必然穿帮
- 先确认成品可从底图重制（保留底图+重制脚本）

- 改前目检放大图、改后立即对比验收

## 四、盲操作法

**何时使用**：AI 会话无法目检图（"内容过滤"等）。

### 步骤

1. **亮度图定版面**
   ```python
   import numpy as np
   from PIL import Image
   im = Image.open("page.png").convert("L")
   arr = np.asarray(im, dtype=np.float32)
   # 行均值 / 列均值 找出分格位置
   row_mean = arr.mean(axis=1)
   col_mean = arr.mean(axis=0)
   ```

2. **像素量气泡**
   ```python
   # 找亮斑（>232）+ 黑边轮廓 → 气泡位置
   from scipy import ndimage
   bright = arr > 232
   lab, n = ndimage.label(bright)
   ```

3. **列出要 Oliver 检查的点**
   - 文字是否清晰可读
   - 构图是否符合预期
   - 颜色是否符合场景色板

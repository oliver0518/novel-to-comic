# Examples · 使用案例

novel-to-comic 是通用方法论，对任何小说都适用。

本文档说明如何把项目落地到你的具体作品。

---

## 通用落地步骤

### 1. 准备文稿

```
你的项目/
├── _文稿/
│   └── <你的小说>_精校版.md
└── 设定大纲.md          # 世界观、势力、人物谱、术语表
```

校对重点：标点统一、章节编号、人物名一致性。

### 2. 做 3 个角色定妆

从出场 ≥2 集的角色开始，按 [`../skills/novel-character-card/SKILL.md`](../skills/novel-character-card/SKILL.md) 流程：
- 写实完整卡（大肖像 + 资料栏 + 刻度三视图 + 微表情 + 服饰图鉴 + 装备图鉴 + 色板）
- Q 版人物卡（同结构但 Q 化）
- 10 张分件源图（仅返修用）

### 3. 做 3 个场景定妆

按场景分级决定要不要出卡：
- 决战场景：必出
- 重要场景：必出
- 门派日常：出一次
- 生活场景：不出

参考 [`../skills/novel-scene-card/SKILL.md`](../skills/novel-scene-card/SKILL.md)。

### 4. 跑通 5-10 集

用任何 5-10 集文字跑完整流水线：
- 漫改大纲 → 节拍表 → 集级设定卡 → 出底图 → 后期 → QA 门禁

熟练后单集可压缩到 30-40 分钟。

### 5. 跑通发布

按 [`../docs/06-publishing.md`](../docs/06-publishing.md) 的发布规范做：
- 一条 5-6 张
- 标题 18-21 字
- BGM 必填真实曲名
- 末页叠关注条

---

## 实战数据

| 维度 | 跑通 5+ 个月后的数据 |
|------|---------------------|
| 单集出图时间（熟练后） | 30-40 分钟 |
| 单集出图时间（首次） | 60-90 分钟 |
| 撞脸返工率 | 从 30% 降到 5% |
| 道具带字返工率 | 从 20% 降到 2% |
| QA 门禁拦截的 ERROR 数 | 平均 1.5 个/集 |

## 复用建议

### 如果你是新人

1. **从角色定妆开始**——这是基础
2. **先做 3 个角色的定妆**——找到节奏感
3. **用一份小说跑 5-10 集**——找到流水线节奏
4. **跑通 QA 门禁**——保证下限
5. **再扩展场景定妆**——提升上限

### 如果你只想用工具

不需要读 docs，直接看：

### 如果你要派 AI 助手做

把 `SKILL.md` 加载到 AI 助手里，说一句：

> "我要把《XXX》小说改成漫画。先帮我做角色定妆。"

AI 会自动按 `skills/novel-character-card/SKILL.md` 的流程做事。

## 横向对比

novel-to-comic 不是唯一的方法论。常见的替代方案：

| 方案 | 优势 | 劣势 |
|------|------|------|
| **novel-to-comic（本项目）** | 通用化方法论 + 工具，跨项目可复用 | 需要自己跑 AI 工具链 |
| **传统漫改工作室** | 真人画师，画质上限高 | 一周 5–10 页，慢 |
| **ComicStudio / CSP** | 桌面工具成熟 | 上手成本高 |
| **NovelAI / NAI** | 出图工具现成 | 一致性差，不适合连载 |
| **Live2D / 视频漫剧** | 形态新颖 | 不是静态漫画 |

novel-to-comic 的定位：**让 AI 生图在视觉一致性上达到可用水平**，不替代画师，但比纯 NAI 强。
